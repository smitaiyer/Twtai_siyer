# Code Review

## What it does
Performs a thorough review of your code looking for potential bugs, security vulnerabilities, performance issues, and readability improvements.

## How to use it
Select code in your editor or describe the file you want reviewed, then run:
```
/community-skills-plugin:code-review
```

## Example usage
Select a function and run the skill to get actionable feedback on:
- Potential bugs or edge cases
- Security concerns
- Performance optimizations
- Code clarity and best practices

## Features
- Identifies bugs and edge cases
- Flags security vulnerabilities
- Suggests performance improvements
- Recommends readability enhancements
- Provides actionable feedback

## Input
- Selected code, file path, or code snippet
- Programming language context

## Output
- Structured review with findings
- Severity levels for each issue
- Suggested improvements
- Code examples for fixes

## Tips
- Use before committing code
- Request specific review focus (security, performance, etc.)
- Combine with other skills like `simplify` or `add-tests`
